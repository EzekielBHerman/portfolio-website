HOW TO OPEN THE WEBSITE
-----------------------
1. Extract the ZIP file.
2. Open the "ezekiel_portfolio_restructured" folder in Visual Studio Code.
3. If you have a profile picture, copy it into the images folder and name it:
   profile.jpg
4. Open index.html in a web browser, or use the Live Server extension in VS Code.
5. Add your CV PDF to the main folder and name it RESUME.pdf if you want the
   Download My CV link to point to your own CV.

CLASS PRESENTATION NOTES
------------------------
1. HTML5 gives the page its structure. Sections, headings, paragraphs, links,
   forms, images and navigation are written in HTML.
2. style.css controls the appearance: colours, fonts, spacing, cards, layout
   and responsive design.
3. script.js adds the interactive parts, including the dark mode button,
   mobile navigation, CV preview, copy-number buttons and WhatsApp forms.
4. CSS Grid is used to arrange project and service cards in columns.
5. Flexbox is used for navigation, buttons and skill tags.
6. The viewport meta tag helps the page display correctly on mobile screens.
7. Image alt text describes images for visitors who cannot see them and for
   assistive technologies.
